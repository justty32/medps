全部是 POD aggregate + serialize() 成員；entity 之間的參照存 entt::entity。

鐵律：新增 component 必須同步登記 serialize/all_components.h 的 AllComponents，否則存檔會默默漏掉它（見第 4 站）。

看什麼

  • Position{x,y,z}：z 即 Zone::layers 的鍵；有 .x/.y 故滿足 tdarray 的 is_coor concept。 position.h:7
  • Velocity{dx,dy}：每 tick 移動步（示範用）。 velocity.h:5
讀完該能回答：新增一個 component 除了寫 struct 本身，還必須改哪個檔？
