第 5 站 GlobalManager — 總管

2 個檔案，共 168 行 · 對照 CODE_TOUR.md

一個 zone = 一個 entt::registry，由 GlobalManager 集中管理；root 永久存活、放全局實體（陣營 / 神祇 / 具名角色），其餘 zones 按需載入卸載。

header 的 API 註解已寫得很完整；.cpp 每個函式都在 10 行以內。

看什麼

  • create：植入 ZoneMeta placeholder（可在 orphans() 中存活）。 global_manager.cpp:24
  • load：store 沒有該 key 時「靜默給空 registry」——目前語意如此，不是 bug。 global_manager.cpp:34
  • unload：先序列化落盤，再從記憶體卸除。 global_manager.cpp:45
  • tick：對每個已載入 zone × 每個 system 依註冊順序跑；root 不參加 tick。 global_manager.cpp:90
  • init_world：assert 檢查 valid_world_dim，冪等覆寫 ROOT singleton。 global_manager.cpp:66
  • save_all：root + 所有已載入 zone 寫入 store（不卸除），最後 flush。 global_manager.cpp:52
讀完該能回答：load() 一個 store 裡不存在的 key 會發生什麼事？root 為什麼被排除在 tick() 之外？
