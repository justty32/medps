tdarray<T> 用單一 vector 打平存 2D 格網（索引 = x*sy + y），已 cereal 化，是 Zone::layers 的底層容器。

使用前必知三個慣例（檔頭註解也有）：回傳 bool 的操作一律「true = 失敗 / 越界 / 中斷」；座標參數可傳 pair / tuple / 任何有 .x/.y 的型別；取值家族 get/getref（未檢查、參照）、getptr（檢查、可 nullptr）、getval（複本、可帶 default）。

看什麼

  • is_coor concept：Position 這種有 .x/.y 的 component 可直接當座標傳入。 tdarray.hpp:25
  • row-major 索引的實作位置。 tdarray.hpp:86
  • operator[] 傳整數時回傳「列指標」供 arr[x][y] 用，且不做越界檢查。 tdarray.hpp:203
  • mydef.h 的巨集都附使用範例註解，掃過即可。 mydef.h:3
讀完該能回答：arr.set(x, y, v) 回傳 true 代表什麼？（提示：跟直覺相反。）

12// 單一 std::vector 打平存放，row-major：索引 = x*sy + y（x 是「列」，y 是「行」）。
13// 已 cereal 化（serialize 存 sx, sy, vec），是 Zone::layers 等格網的底層容器。

15// 使用前必知的三個慣例：
16// 1. 回傳 bool 的操作（alloc/out/set/each…）一律「true = 失敗 / 越界 / 提早中斷」，
17// 與直覺相反，呼叫端請注意。
18// 2. 座標參數凡是接受 is_coor 的 overload，可傳 pair<int,int>、tuple<int,int>，
19// 或任何有 .x/.y 成員的型別（例如 components/position.h 的 Position）。
20// 3. 取值家族的差異：get/getref = 未檢查、回傳參照（兩者等價）；

25concept is_coor = std::is_same_v<T, std::pair<int, int>>
26 || std::is_same_v<T, std::tuple<int, int>>
27 || requires(T t) { t.x; t.y; };

33 // bx/by：把任意 is_coor 型別統一解出 x / y 分量。
34 template<is_coor TC>
35 inline constexpr int bx(TC t) {
36 if constexpr (std::is_same_v<TC, std::pair<int, int>>) return t.first;
37 else if constexpr (std::is_same_v<TC, std::tuple<int, int>>) return std::get<0>(t);
38 else return t.x;
39 }
40 template<is_coor TC>
41 inline constexpr int by(TC t) {
42 if constexpr (std::is_same_v<TC, std::pair<int, int>>) return t.second;
43 else if constexpr (std::is_same_v<TC, std::tuple<int, int>>) return std::get<1>(t);
44 else return t.y;
45 }

47public:

55 }

60 && static_cast<size_t>(sx) * sy == vec.size(); }

176 // copy_from 會先 clear 再改成 target 的維度。
177 tdarray<T> copy_to(){
178 if (unusable()) return tdarray<T>();

180 if constexpr (std::is_trivially_copyable<T>::value) {
181 std::copy(vec.begin(), vec.end(), ta.vec.begin());

183 else {

192 if constexpr (std::is_trivially_copyable<T>::value) {
193 std::copy(target.vec.begin(), target.vec.end(), vec.begin());
194 }
195 else {
196 for(int i = 0 ; i < vec.size() ;i++) vec[i] = target.vec[i];
197 }

201 // 供 arr[x][y] 兩段式索引使用。注意整數版不做越界檢查。
202 template<typename TC>
203 auto operator [](TC c) {
204 if constexpr (is_coor_v<TC>) return getref(c);
