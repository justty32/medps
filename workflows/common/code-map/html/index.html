架構不變量（修改前必知）

  • 多 registry / zone 生命週期——一個 zone = 一個 Zone（繼承基底，registry＋自帶多層地圖），由 ZoneManager 管理；root 永久存活、放全局實體，其餘 zones 按需載入/卸載。zone id 是零語意單調序號、由 create_child 單點配發，磁碟 path 由 id 推導、不另存全域 zone 清單。World 是目前唯一子類，經 ZoneKind tag／make_zone／zone_cast<T> 分派。
  • 序列化——EnTT snapshot 遍歷 registry，cereal PortableBinaryArchive 負責位元格式，透過 entt_cereal_archive.h 橋接。component 型別清單的單一來源是 all_components.h 的 AllComponents，save/load 兩邊共用。存檔無版本欄位——格式變更＝刪存檔目錄。
  • 元件即資料——component 盡量是 POD aggregate；entity 之間的參照存 entt::entity。system 寫成吃 Zone& 的自由函式；位置變更一律收口於 systems::move_by。
  • actor＝組合而非繼承——地點/部隊的共同基底不是 C++ 父類，是共用元件（Name＋Owner＋Location{kind}／Unit{kind}）。種類是資料驅動 def（住在 root 的實體），actor 以穩定 uint64_t id 參照，跨 registry 安全。
